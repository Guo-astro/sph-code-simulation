================================================================================
COMMON ERRORS TO CHECK
================================================================================

1. SIGN ERRORS:
   - Momentum/energy evolution should be NEGATIVE: dS/dt = -f ✓
   - Taub b coefficient: b = -(a-1), NOT -(a+1) ✓
   - Mass flux: j² = -(P-Pa)/(...) for compression ✓

2. MISSING FACTORS OF c:
   - Lorentz factor: γ = 1/√(1 - v²/c²), not 1/√(1 - v²) ✓
   - Enthalpy: H = 1 + u/c², not H = 1 + u ✓
   - Sound speed formula is dimensionless (no c) ✓

3. WRONG VELOCITY IN ENERGY:
   - Should use v*, NOT (v* - v_i) ✓
   - This is correct for canonical energy e = γH - P/(Nc²)

4. LORENTZ FACTOR:
   - Must include tangential velocity: v² = v_n² + v_t² ✓
   - Not just normal component!

5. DENSITY CONFUSION:
   - N = lab-frame density (used in SPH sums) ✓
   - n = rest-frame density (used in EOS) ✓
   - Relation: N = γn ✓

================================================================================
QUICK FORMULA VERIFICATION PROCEDURE
================================================================================

When you find a potential bug:

1. Note the LINE NUMBER in the code
2. Look up the corresponding FORMULA above
3. Check the PAPER reference
4. Verify each term:
   - Correct sign (+/−)?
   - Correct factors (c, c², γ_c, etc)?
   - Correct variable (N vs n, H vs h, etc)?
5. Check special cases:
   - What if v → 0? Should → non-relativistic limit
   - What if v → c? Should → ultra-relativistic limit
   - What if P → 0? Should → vacuum

EXAMPLE:
  Code line 898: b_term = -(gamma_c - 1.0) * (Pa - P) / (gamma_c * P)

  Check 1: Sign? Should be negative → ✓
  Check 2: Factor (γ_c-1)? → ✓
  Check 3: Denominator γ_c·P? → ✓
  Check 4: Equals -(a-1)? Let's verify:
           a = 1 + (γ_c-1)(Pa-P)/(γ_c·P)
           a - 1 = (γ_c-1)(Pa-P)/(γ_c·P)
           -(a-1) = -(γ_c-1)(Pa-P)/(γ_c·P) → ✓ MATCHES

  Conclusion: Formula is CORRECT
