### Data Embedded

For each column density (N_H = 10^19 and 10^20 cm^-2):
- **65 density points** from 10^-2 to 10^6 cm^-3
- **Equilibrium temperature** T_eq(n)
- **Equilibrium pressure** P_eq(n)
- **H2 fraction** x_H2(n) 
- **CO fraction** x_CO(n)
- **Electron fraction** x_e(n)

Total: ~780 data points embedded as constexpr arrays.
