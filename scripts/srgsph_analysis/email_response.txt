- Canonical energy: Sum of nu_i * e_i, where e = gamma * H - P/N

2. SECOND-ORDER ACCURACY AND GRADIENT EVALUATION
================================================================================

CURRENT CONFIGURATION: use2ndOrderSRGSPH = false (1st order scheme)

When 2nd order is enabled, the MUSCL reconstruction uses:

GRADIENT EVALUATION (src/srgsph/sr_pre_interaction.cpp):
    grad_A_i = Sum_j V_p,j * (A_j - A_i) * nabla_W_ij

INTERFACE RECONSTRUCTION (src/srgsph/sr_fluid_force.cpp):
    A_L = A_i + grad_A_i . dr_i  (left state at interface)
    A_R = A_j + grad_A_j . dr_j  (right state at interface)

SHOCK/CD LIMITER:
    - Shock detection: C_shock * |e_ij . dv| > c_s => fallback to 1st order
    - Contact discontinuity: |log10(P_i/P_j)| > C_cd => fallback to 1st order

The overshoot at the rarefaction head can occur even with 1st order due to:
- Insufficient particle resolution at sharp gradients
- Riemann solver discretization effects
- Kernel width influence (SRGSPH uses h = sqrt(2) * h_i)

================================================================================
3. RIEMANN SOLVER
================================================================================

SOLVER TYPE: Exact Riemann Solver (Pons et al. 2000)
IMPLEMENTATION: src/srgsph/sr_exact_riemann.cpp

ALGORITHM:
1. Define residual f(P) = v_L^x(P) - v_R^x(P)
2. Use bisection to find P* where f(P*) = 0 (tolerance: 1e-10)
3. For each wave:
   - If P* > P_a: Shock wave -> solve_shock() using Taub adiabat
   - If P* < P_a: Rarefaction wave -> solve_rarefaction() using RK4 ODE integration

RAREFACTION ODE INTEGRATION:
- Method: 4th order Runge-Kutta (RK4)
- Step count: Adaptive, 64-2048 steps depending on pressure span
- ODE: dv^x/dP = +/- 1/(n*H*gamma^2*c_s*sqrt(1+g))

FLAT REGIONS IN RAREFACTION:
The flat regions observed inside the rarefaction wave are likely caused by:
1. Discrete ODE integration stepping in solve_rarefaction()
2. Characteristic speed (xi) calculation discretization
3. The correction factor g = (v_t^2 * (xi^2 - 1)) / (1 - xi*v_x)^2 
   becoming large in certain regions

HLLC FALLBACK:
When the exact solver fails to converge, HLLC is used as a fallback:
    if (!converged) {
        riemann::hllc_riemann_solver(...);
    }
